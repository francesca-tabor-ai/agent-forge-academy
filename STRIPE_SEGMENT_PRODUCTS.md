# Stripe Segment Subscription Products

This file contains all Stripe product and price IDs for segment-based subscriptions (Track, Industry, Role).

## Format

Each segment subscription has:
- **Product ID**: Stripe product identifier
- **Monthly Price ID**: Stripe price ID for monthly billing
- **Annual Price ID**: Stripe price ID for annual billing
- **Marketing Copy**: Description and value proposition

## Notes

- All prices are in GBP (£)
- Annual subscriptions save approximately 2 months (16.67% discount)
- Product IDs and Price IDs are placeholders - replace with actual Stripe IDs after creating products in Stripe Dashboard
- To create products:
  1. Go to Stripe Dashboard → Products
  2. Create a product for each segment
  3. Add monthly and annual prices
  4. Update this file with the actual IDs

## Usage in Code

Access segment subscription data via:
- `lib/utils/segment-subscriptions.ts` - Utility functions to get product/price IDs
