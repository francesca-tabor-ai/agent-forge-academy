## 🔧 Technology Reference

### Frontend Technologies
- **React** - UI framework (Modules 2, 5)
- **React Three Fiber** - 3D rendering (Modules 2, 3)
- **Three.js** - 3D graphics library (Modules 2, 3)
- **glTF/GLB** - 3D format (Modules 3, 4)
- **USDZ** - iOS format (Module 3)

### Backend Technologies
- **Node.js & Express** - Server framework (Module 2)
- **MongoDB** - Database (Module 2)
- **AWS EC2** - Compute (Module 2, 6)
- **AWS Lambda** - Serverless (Module 2, 5)
- **S3** - Storage (Module 2, 6)

### 3D Tools
- **Blender** - 3D modeling/rendering (Module 2)
- **Draco** - Compression (Module 3)
- **Meshopt** - Optimization (Module 3)

### E-Commerce APIs
- **Amazon Selling Partner API** - Catalog integration (Module 4)
- **Amazon Seller App** - Mobile scanning (Module 4)

### Advanced Features
- **AI Object Recognition** - Video shopping (Module 5)
- **Ready Player Me API** - Avatar generation (Module 5)
- **Dynamic Product Placement** - Personalization (Module 5)
