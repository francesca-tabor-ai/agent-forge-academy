# AI-Powered Organisational Knowledge & Consistency at Scale

## From Tribal Memory to Organisational Advantage

---

## Course Overview

**Audience:** All delivery, creative, commercial teams; new joiners; team leads; capability heads

**Course Promise (the vibe):**

> "You will stop reinventing work the organisation has already mastered — without turning creativity into bureaucracy."

This is not a knowledge-management course.  
It is a scale, quality, and confidence course.

---

## THE VIBE (DESIGN PRINCIPLES)

- **Knowledge must show up when you need it**
- **Experience only counts if it's reusable**
- **Consistency is safety, not sameness**
- **Guidance beats documentation**
- **Learning compounds or it disappears**

**Tone:** confident, generous, pragmatic  
**Energy:** elite apprenticeship + modern product design  
**Outcome:** people feel supported, not constrained

---

## COURSE STRUCTURE

**5 CORE MODULES + 1 APPRENTICESHIP LAB**

Each module tackles a real organisational failure pattern teams quietly accept as "just how it is".

### Module 1: Stop Searching. Start Being Answered.
**Problem:** Knowledge fragmentation  
**Capability:** AI Knowledge Assistant

### Module 2: Onboarding Is a Performance Problem
**Problem:** Slow onboarding  
**Capability:** Role-Based Onboarding Guides

### Module 3: Experience Is a Pattern, Not a Story
**Problem:** Reinventing solutions  
**Capability:** "What Worked Before" Prompts

### Module 4: Kill the Zombie Playbook
**Problem:** Outdated playbooks  
**Capability:** Auto-Refresh Knowledge Links

### Module 5: Nudge, Don't Nag
**Problem:** Low engagement with knowledge  
**Capability:** Contextual Workflow Nudges

### Apprenticeship Lab: The AI Mentor
**Wild Capability:** AI Mentor for Junior Staff  
**Exploration:** Scaling judgement, not answers

---
