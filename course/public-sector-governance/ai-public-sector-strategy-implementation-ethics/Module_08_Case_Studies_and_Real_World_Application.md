# Module 8: Case Studies and Real-World Application

**Objective:** Analyze current public sector deployments to understand practical successes and failures.

## Learning Objectives

- Learn from GOV.UK Chat RAG pilot
- Understand NHS AI deployments for healthcare
- Analyze operational efficiency use cases
- Conduct user research for AI products

## Core Topics

### 8.1 GOV.UK Chat

**Lessons from the RAG (Retrieval Augmented Generation) Pilot:**

**What is RAG?**
- Retrieval Augmented Generation
- Combines information retrieval with text generation
- Retrieves relevant documents, then generates answers
- Reduces hallucination by grounding in source material

**GOV.UK Chat Implementation:**
- RAG-based chatbot for government information
- Retrieves relevant GOV.UK content
- Generates answers based on retrieved content
- Provides source citations

**Key Lessons:**

**Accuracy:**
- RAG improves accuracy over pure generation
- Source grounding reduces hallucinations
- Citation enables fact-checking
- Still requires human review for critical information

**User Trust:**
- Transparency about AI use builds trust
- Source citations increase credibility
- Clear limitations manage expectations
- User feedback improves system

**Challenges:**
- Retrieval quality affects answer quality
- Need for high-quality source content
- Balancing accuracy with helpfulness
- Managing user expectations

**Success Factors:**
- High-quality source content
- Effective retrieval mechanisms
- Clear communication to users
- Continuous improvement

### 8.4 User Research

**Conducting User Research Specifically for AI Products:**

**Measuring Trust:**
- Understanding user trust in AI
- Factors affecting trust
- Building trust through design
- Monitoring trust over time

**Trust Factors:**
- Transparency about AI use
- Accuracy and reliability
- Fair and non-discriminatory
- Human oversight
- Redress mechanisms

**Mental Models:**
- Understanding how users think about AI
- User expectations and assumptions
- Misconceptions and concerns
- Education and communication needs

**Research Methods:**
- User interviews
- Surveys and questionnaires
- Usability testing
- Observation studies
- Feedback collection

**Key Questions:**
- Do users understand AI is being used?
- Do users trust AI outputs?
- What are user concerns?
- How do users want to interact with AI?
- What support do users need?

**Design Implications:**

- Feedback mechanisms

3. **Operational efficiency is achievable:** Appropriate use cases deliver value
4. **User research is critical:** Understanding trust and mental models is essential
