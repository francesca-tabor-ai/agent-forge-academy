# Module 2: AI for Data Liberation and Digitization

**Learning Objective:** Examine the technical capabilities of AI in converting historic, unstructured planning data into usable digital assets.

## Learning Objectives

- Understand the Extract tool and its technical process
- Analyze efficiency metrics and accuracy improvements
- Recognize the shift to machine-readable plans
- Explore the role of Planning Data platform

## Core Topics

### Topic A: The "Extract" Tool

**Deep Dive into Government's Extract Tool:**

**Development:**
- Government and Incubator for AI (i.AI) collaboration
- Uses Google DeepMind's Gemini model
- Converts historic planning documents
- Unlocks trapped data

**Technical Process:**

**Vision Language Models (VLMs):**
- Understand visual information
- Extract text from images
- Analyze maps and documents
- Process unstructured data

**Segment Anything Model (SAM):**
- Trace geospatial boundaries
- Extract polygons from maps
- Georeference spatial data
- Identify geographic features

**Workflow:**
1. Input: Historic documents (paper/digital)
2. VLM: Extract text and understand content
3. SAM: Trace geospatial polygons
4. Georeference: Link to geographic coordinates
5. Output: Structured, machine-readable data

**Efficiency Metrics:**

**Time Reduction:**
- **Before:** Hours per document
- **After:** Minutes per document
- **Improvement:** 20-40x faster

**Accuracy:**
- **Dates:** 94% accuracy
- **Shapes:** 90% accuracy
- **Text Fields:** High accuracy
- **Quality:** Production-ready

**Impact:**
- Unlocks historical data
- Enables modern use
- Supports decision-making
- Transforms legacy information

### Topic B: Standardizing Data

**The Shift Toward Machine-Readable Plans:**

**Current State:**
- Plans in PDF format
- Human-readable only
- Cannot be processed automatically
- Difficult to check compliance

**Machine-Readable Plans:**
- Policies translated into computational rules
- Structured data formats
- Automated processing possible
- Compliance checking enabled

**Benefits:**
- Automated compliance checking
- Faster processing
- Consistent application
- Reduced errors

**The Planning Data Platform:**

**Purpose:**
- Host open, standardized datasets
- Reduce "scraping and cleaning" time
- Enable PropTech innovation
- Support data-driven planning

**Benefits for PropTech:**
- **Reduced Time:** Less data preparation
- **Standardized Format:** Consistent data
- **Access:** Easy data access
- **Innovation:** Enables new tools

**Open Data:**
- Publicly accessible
- Standardized formats
- Regular updates
- Quality assured

## Technical Architecture

**Data Liberation Process:**
- **Input:** Historic documents
- **Processing:** VLM + SAM extraction
- **Output:** Structured data
- **Platform:** Planning Data platform

**Standardization:**
- Common data models
- Interoperable formats
- Shared standards
- Integration enabled

## Key Takeaways

1. **Extract unlocks data:** VLM and SAM convert historic documents to digital assets
2. **Significant efficiency:** Hours to minutes, high accuracy (94% dates, 90% shapes)
3. **Machine-readable plans:** Policies as computational rules enable automation
4. **Planning Data platform:** Open, standardized data enables PropTech innovation
