# Module 6: Rebuilding State Capacity and Implementation

**Focus:** The practicalities of rolling out AI in government.

## Learning Objectives

- Understand procurement reform for Local Planning Authorities
- Recognize cultural change and skills gap challenges
- Explore standardization requirements
- Analyze future outlook and digitization timeline

## Core Topics

### Procurement Reform

**Overcoming the Procurement Hurdle:**

**The Problem:**
- LPAs struggle with procurement
- Complex processes
- Limited resources
- Difficult to access innovation

**Digital Planning Directory:**
- Directory of digital tools
- Pre-approved solutions
- Easier procurement
- Access to innovation

**PropTech Innovation Fund:**
- Funding for innovation
- Support for LPAs
- Access to new tools
- Reduced procurement barriers

**Benefits:**
- Faster procurement
- Access to innovation
- Reduced costs
- Better tools

**Challenges:**
- Still need to evaluate tools
- Integration requirements
- Training needs
- Change management

### Cultural Change

**Addressing the Skills Gap:**

**The Problem:**
- Only minority of LPAs feel equipped
- Limited digital skills
- Lack of understanding
- Resistance to change

**Skills Gap:**
- Cannot identify digital tools
- Don't understand capabilities
- Lack technical knowledge
- Need training and support

**Institutional Stability:**
- Constant reorganization destroys capability
- Need for stable institutions
- Accumulate expertise over time
- Build institutional memory

**Why Stability Matters:**
- Expertise accumulates
- Institutional memory builds
- Capability develops
- Trust established

**Change Management:**
- Training programs
- Support and resources
- Cultural shift
- Leadership commitment

### Standardization

**The Necessity of Open, Standardized Data:**

**Planning Data Platform:**
- Common data platform
- Standardized formats
- Open data access
- Enables innovation

**Why Standardization Matters:**
- **Interoperability:** Systems work together
- **Innovation:** Private sector can build tools
- **Scalability:** Solutions work across authorities
- **Efficiency:** Reduced duplication

**Open Standards:**
- Not proprietary
- Accessible to all
- Enables competition
- Supports innovation

**Private Sector Innovation:**
- Standardized data enables tools
- Scalable software solutions
- Competition and choice
- Innovation and improvement

**Benefits:**
- Better tools available
- Competition drives quality
- Lower costs
- Continuous improvement

### Future Outlook

**Timeline for Full Digitization:**

**2026 Target:**
- Full digitization of English planning system
- All systems digital
- Integrated platforms
- Modern infrastructure

**1.5 Million Homes Target:**
- Housing delivery goal
- AI enables faster processing
- Supports delivery
- Critical for meeting target

**Key Milestones:**
- Data digitization
- System integration
- Tool deployment
- Full rollout

**Challenges:**
- Technical complexity
- Resource requirements
- Change management
- Integration needs

**Success Factors:**
- Clear roadmap
- Adequate resources
- Strong leadership
- Stakeholder engagement

## Implementation Framework

**Key Elements:**
- **Procurement:** Reform to enable access
- **Culture:** Skills and change management
- **Standards:** Open, standardized data
- **Timeline:** Clear roadmap to 2026

**Success Requirements:**
- Political commitment
- Adequate funding
- Technical capability
- Cultural change

## Key Takeaways

1. **Procurement reform needed:** Digital Planning Directory and PropTech Fund reduce barriers
2. **Skills gap is real:** Only minority of LPAs feel equipped, need training
3. **Standardization essential:** Open, standardized data enables innovation and scalability
4. **2026 target ambitious:** Full digitization by 2026 requires significant effort

## Reflection Questions

1. How can procurement reform (Digital Planning Directory, PropTech Fund) enable AI adoption in LPAs?
2. What are the skills gaps in LPAs, and how can they be addressed?
3. Why is institutional stability important for building AI capability?
4. How does standardization (Planning Data Platform) enable private sector innovation?
5. Is the 2026 target for full digitization realistic, and what are the key success factors?
