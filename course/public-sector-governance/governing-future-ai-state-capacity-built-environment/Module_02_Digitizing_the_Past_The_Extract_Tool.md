# Module 2: Digitizing the Past – The "Extract" Tool

**Focus:** The technical and practical application of AI in unlocking historical data.

## Learning Objectives

- Understand the Extract initiative and collaboration
- Analyze the technical workflow combining LLMs, VLMs, and SAM
- Evaluate performance metrics and accuracy improvements
- Recognize the importance of evaluation-driven development

## Core Topics

### The "Extract" Initiative

**Deep Dive into MHCLG and i.AI Collaboration:**

**Partners:**
- **MHCLG (Ministry of Housing, Communities and Local Government):** Now DLUHC
- **i.AI (Incubator for AI):** Government AI innovation unit
- **Google DeepMind:** Gemini model provider

**Purpose:**
- Digitize historical planning documents
- Unlock trapped data
- Enable modern data use
- Transform legacy information

**Scope:**
- Historical planning documents
- Paper and digital archives
- Maps and spatial data
- Text and structured information

**Benefits:**
- Make historical data accessible
- Enable search and analysis
- Support modern decision-making
- Preserve historical information

### Technical Workflow

**How AI Agents Combine Technologies:**

**Large Language Models (LLMs):**
- Text extraction from documents
- Understanding document content
- Structured data extraction
- Information parsing

**Vision Language Models (VLMs):**
- Understanding visual information
- Image and map analysis
- Spatial information extraction
- Visual data processing

**Segment Anything Model (SAM):**
- Geospatial polygon tracing
- Boundary identification
- Spatial feature extraction
- Map digitization

**AI Agents:**
- Combine multiple AI models
- Orchestrate workflows
- Handle complex tasks
- Ensure accuracy

**Workflow:**
1. Document input (paper or digital)
2. LLM extracts text and structured data
3. VLM analyzes images and maps
4. SAM traces geospatial polygons
5. Output structured, machine-readable data

### Performance & Metrics

**Analyzing the Shift in Efficiency:**

**Time Reduction:**
- **Manual:** 1-2 hours per document
- **AI-Assisted:** 3 minutes per document
- **Efficiency Gain:** 20-40x faster
- **Scalability:** Can process thousands of documents

**Accuracy Metrics:**
- **Text Fields:** 100% accuracy
- **Dates:** 94% accuracy
- **High Quality:** Meets production standards
- **Reliable:** Consistent performance

**Cost-Benefit:**
- Significant time savings
- Reduced manual labor
- Faster digitization
- Better data access

**Scalability:**
- Can process large volumes
- Consistent quality
- Automated workflow
- Reduced human error

### Evaluation-Driven Development

**The Importance of Testing Against Ground Truth:**

**Ground Truth Data:**
- Manually verified correct data
- Reference standard for evaluation
- Used to test AI accuracy
- Ensures quality before rollout

**Testing Process:**
- Compare AI outputs to ground truth
- Measure accuracy and errors
- Identify improvement areas
- Validate before deployment

**Why It Matters:**
- Ensures accuracy
- Prevents errors
- Builds confidence
- Enables safe rollout

**Before National Rollout:**
- Comprehensive testing
- Accuracy validation
- Error analysis
- Quality assurance

**Evaluation Framework:**
- Accuracy metrics
- Error analysis
- Quality assessment
- Performance monitoring
