## 🔧 Technology Reference

### Frameworks Covered
- **LangChain** - RAG orchestration (Modules 2, 3, 7)
- **LangGraph** - State management (Modules 2, 3, 7)
- **LlamaIndex** - Data framework (Modules 4, 7)
- **AutoGen** - Multi-agent (Modules 3, 7)
- **CrewAI** - Collaborative agents (Modules 3, 7)

### Databases Covered
- **Vector Stores** - Qdrant, Pinecone, Weaviate (Modules 4, 7)
- **Graph Databases** - Memgraph, Neo4j (Modules 4, 7)
- **Hybrid Architectures** - Vector + Graph (Module 4)

### Observability Tools
- **Langfuse** - Monitoring, cost, latency (Module 7)
- **Custom Dashboards** - Metrics visualization (Module 7)
