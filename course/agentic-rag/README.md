# Mastering Agentic RAG for Enterprise AI

##  Course Overview

**Duration:** 7 weeks  
**Level:** Intermediate to Advanced  
**Time Commitment:** 6-8 hours per week  
**Prerequisites:** Python, basic RAG knowledge, LLM understanding

---

##  What You'll Master

By completing this course, you will be able to:

 Design and architect agentic RAG systems  
 Build self-correcting and adaptive retrieval systems  
 Implement specialized agentic RAG frameworks (CRAG, Adaptive RAG, Graph-based)  
 Deploy enterprise-grade agentic RAG applications  
 Evaluate, secure, and govern agentic systems  
 Optimize for accuracy, cost, and latency

---

##  Course Modules

### [Module 1: Foundations of Retrieval-Augmented Generation](Module_01_Foundations_of_Retrieval-Augmented_Generation.md)
- The Evolution of RAG: From Naïve to Advanced and Modular
- The Gen AI Paradox: Strategic impact without autonomous reasoning
- Traditional vs. Agentic RAG: Static vs. dynamic workflows
- Core Limitations: Query sensitivity, error correction, context fragmentation

### [Module 2: The Agentic Architecture](Module_02_The_Agentic_Architecture.md)
- Anatomy of an AI Agent: LLM, memory, planning, tools
- Specialised Agent Roles: Planner, Retriever, Verifier, Tool Agent
- State Management: Conversational continuity and context
- **Lab 1:** Build a basic agentic RAG system

### [Module 3: Agentic Design and Workflow Patterns](Module_03_Agentic_Design_and_Workflow_Patterns.md)
- Core Patterns: Reflection, planning, tool use
- Collaborative Orchestration: Centralized and decentralized patterns
- Optimisation Workflows: Prompt chaining, routing, evaluator-optimizer
- **Lab 2:** Implement reflection and planning patterns

### [Module 4: Specialised Agentic RAG Frameworks](Module_04_Specialised_Agentic_RAG_Frameworks.md)
- Corrective RAG (CRAG): Self-correcting mechanisms
- Adaptive RAG: Query complexity classification
- Graph-Based Agentic RAG: Knowledge graphs with agentic traversal
- Agentic Document Workflows (ADW): End-to-end automation
- **Lab 3:** Build a CRAG system

### [Module 5: Enterprise Applications and Domain Specialisation](Module_05_Enterprise_Applications_and_Domain_Specialisation.md)
- Software Quality Engineering: 94.8% accuracy with hybrid architectures
- Financial Analysis: Risk assessment, fraud detection
- Healthcare Diagnostics: Multi-step diagnosis with EHR data
- Legal and E-commerce: Contract review, recommendations
- **Lab 4:** Implement domain-specific agentic RAG

### [Module 6: Evaluation, Governance, and Risk Management](Module_06_Evaluation_Governance_and_Risk_Management.md)
- Measuring Success: Agentic metrics (Plan Fidelity, Tool Success Rate)
- Security and Red Teaming: Prompt injection, info disclosure
- Operational Risks: Iterative loops, latency, costs
- Ethics and Governance: GDPR, bias, autonomy boundaries
- **Lab 5:** Implement evaluation and security measures

### [Module 7: Implementation and Tooling Ecosystem](Module_07_Implementation_and_Tooling_Ecosystem.md)
- Frameworks: LangChain, LangGraph, LlamaIndex, AutoGen, CrewAI
- Databases: Vector stores (Qdrant, Pinecone) and graph databases
- Observability: Langfuse for monitoring and optimization
- **Lab 6:** Deploy production system with observability
- **Lab 7:** Capstone project
