# AI-Native App Delivery with Cursor & Supabase

**Complete course on building production applications using Intent-Driven Development**

---

## Course Overview

This course teaches you how to build AI-native applications using Cursor and Supabase. You'll learn the Intent-Driven Development methodology, where plain-English instructions become working production code through AI collaboration.

### What Makes This Course Different?

- **Intent-Driven Development:** Shift from manual implementation to AI-assisted development
- **Scaffolding Strategy:** Build functional UI with mock data first
- **Database-First:** Schema-first thinking with migrations as code
- **Security by Default:** Database-enforced security with RLS
- **Rapid Iteration:** Master the AI-powered debug loop

---

## Course Modules

### Module 1: The Core Methodology & Intent-Driven Development
Learn the philosophy of Intent-Driven Development and understand how to work with AI as a collaborator.

### Module 2: Scaffolding with Cursor Agent
Master Cursor Agent Mode to execute build plans and generate modular components.

### Module 3: Database Engineering & Schema-First Thinking
Set up local Supabase, manage migrations, and integrate with MCP for AI database introspection.

### Module 4: Authentication & Identity Primitives
Implement passwordless OTP, custom auth flows, and anonymous sign-ins.

### Module 5: Security & Row Level Security (RLS)
Move security logic to the database with Postgres RLS policies.

### Module 6: Logic, Intelligence, & Side Effects
Build Edge Functions, event-driven architectures, and realtime-first UIs.

### Module 7: AI-Native Features (Vector & RAG)
Implement semantic search, RAG pipelines, and AI-driven dashboards.

### Module 8: Deployment & the Iteration Loop
Deploy to Supabase Cloud and master rapid iteration with AI-powered debugging.
