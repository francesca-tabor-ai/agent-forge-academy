## Core Mathematics

### Multi-Objective Optimization

**Problem:**
```
Maximize: [f₁(x), f₂(x), ..., fₙ(x)]
Subject to: g(x) ≤ 0
```

**Pareto optimal:**
```
No solution dominates
Trade-off curve
```

**Weighted sum:**
```
Maximize: Σ w_i × f_i(x)
Subject to: Constraints
```

### Scenario Analysis

**Scenarios:**
```
S = {s₁, s₂, ..., s_n}
P(s_i) = Probability
```

**Expected value:**
```
E[Outcome] = Σ P(s_i) × Outcome(s_i)
```

**Robust:**
```
Worst_case: min Outcome(s_i)
Best_case: max Outcome(s_i)
```

### Sensitivity Analysis

**Sensitivity:**
```
∂Objective/∂Parameter
```

**Interpretation:**
```
How much objective changes
With parameter change
```

**Application:**
```
Identify critical_parameters
Focus improvement_efforts
Uncertainty_quantification
```
