# Capstone: Telecom Network Upgrade Design

## Introduction

This capstone module integrates all course concepts to design, analyze, and economically justify a telecom network upgrade. Students apply propagation models, traffic forecasts, optimization methods, and financial metrics.

## Learning Objectives

- Synthesize mathematical concepts across all modules
- Design network upgrade using propagation models
- Forecast traffic and plan capacity
- Optimize resource allocation
- Calculate financial metrics and ROI
- Create economically justified network design

## Integration Requirements

### Propagation Models

**Path loss:**
```
PL = f(Distance, Frequency, Environment)
```

**Coverage:**
```
Coverage_area = f(Path_loss, Power, Antenna)
```

**SINR:**
```
SINR = f(Signal, Interference, Noise)
```

**Integration:**
```
Coverage → Capacity → Revenue
```

### Traffic Forecasts

**Demand:**
```
Demand(t) = f(Historical, Trends, Events)
```

**Capacity:**
```
Capacity_needed = Demand / Utilization
```

**Planning:**
```
When to upgrade
How much capacity
```

### Optimization Methods

**Site selection:**
```
Minimize: Cost
Subject to: Coverage_constraints
```

**Resource allocation:**
```
Maximize: Throughput
Subject to: Power_constraints
```

**Multi-objective:**
```
Balance: Coverage, Capacity, Cost
```

### Financial Metrics

**NPV:**
```
NPV = -Investment + Σ Cash_flow_t / (1 + r)^t
```

**IRR:**
```
Solve: 0 = -Investment + Σ Cash_flow_t / (1 + IRR)^t
```

**ROI:**
```
ROI = (Returns - Investment) / Investment
```

**Payback:**
```
Time to recover investment
```
