## Exercise Index

### Module 1
**Exercise:** Decompose your current sales org into tasks, decisions, and signals
- Identify all tasks in your sales process
- Map decision points
- List signals that trigger actions

### Module 2
**Exercise:** Build your full agent org map (CSO → Teams → Specialists)
- Design agent hierarchy
- Define roles and responsibilities
- Map communication flows

### Module 3
**Exercise:** Build a CSO agent that runs a daily/weekly sales standup autonomously
- Implement delegation logic
- Create prioritization system
- Design escalation triggers

### Module 4
**Exercise:** Launch one prospect through 5 channels + 3 languages autonomously
- Deploy multichannel agents
- Handle multilingual context
- Coordinate handoffs

### Module 5
**Exercise:** Build an agent that detects pipeline anomalies and proposes fixes
- Monitor pipeline health
- Identify anomalies
- Generate fix recommendations

### Module 6
**Exercise:** Run a full discovery cycle without human prep
- Automate qualification
- Generate discovery questions
- Synthesize insights

### Module 7
**Exercise:** Auto-generate a proposal + FAQ from a discovery call
- Extract call insights
- Generate proposal
- Create FAQ from objections

### Module 8
**Exercise:** Design your "kill switch" and escalation framework
- Define kill switch triggers
- Create escalation paths
- Test failure scenarios
