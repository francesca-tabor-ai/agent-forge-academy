## 0.1 Why 2026 ≠ Prompt Engineering, But Workflow Engineering

### The Prompt Engineering Trap

**Traditional Approach:**
```
Better Prompt → Better Image → Manual Iteration → One-off Output
```

**The Problem:**
- Each image requires manual prompt refinement
- No reusability across products
- No systematic variation
- No scalability

**The Reality:**
- Prompt engineering optimizes for **one image**
- Workflow engineering optimizes for **entire systems**
- The moat is in the **system**, not the prompt

### From Prompt to Workflow

**Prompt Engineering (2024):**
- Focus: "How do I get this one image right?"
- Skill: Crafting perfect prompts
- Output: Single images
- Scale: Linear (1 prompt = 1 image)

**Workflow Engineering (2026):**
- Focus: "How do I generate 10,000 consistent images?"
- Skill: Designing reusable systems
- Output: Automated pipelines
- Scale: Exponential (1 workflow = infinite images)

## 0.2 From Key Visual → Creative Graph

### The Old Model: Key Visual

**Traditional Creative Process:**
```
Brief → Concept → Key Visual → Manual Variations → Campaign
```

**Characteristics:**
- One hero image
- Manual variations
- Limited scalability
- High cost per asset

**Example:**
- Create 1 hero image for product launch
- Manually create 5 variations for different channels
- Total: 6 images, 2 weeks, $5,000

### The New Model: Creative Graph

**Automated Creative Process:**
```
Brief → Creative Graph → Automated Variations → Full Campaign
```

**Characteristics:**
- One system
- Infinite variations
- Unlimited scalability
- Low cost per asset

**Example:**
- Design 1 creative system
- Automatically generate 500 variations for all channels
- Total: 500 images, 2 hours, $500

### What is a Creative Graph?

A **creative graph** is a structured workflow that:
- Takes inputs (products, briefs, constraints)
- Applies transformations (art direction, product insertion, localization)
- Generates outputs (images, videos, assets)
- Maintains consistency across all variations

**Components:**
- **Nodes:** Processing steps (concept generation, art direction, product insertion)
- **Branches:** Conditional logic (if product type X, use style Y)
- **Loops:** Iteration over products, variants, channels
- **Constraints:** Brand guidelines, technical requirements

## 0.3 Creative Scalability as a Growth Lever

### The Scalability Equation

**Traditional Model:**
```
Cost per Asset = Fixed Cost / Number of Assets
As assets increase → cost per asset stays constant
```

**Automated Model:**
```
Cost per Asset = System Cost / Number of Assets
As assets increase → cost per asset approaches zero
```

### Real-World Impact

**Scenario: Seasonal Catalog Refresh**

**Traditional Approach:**
- 1,000 products
- 1 image per product
- $50 per image
- 2 months timeline
- **Total: $50,000, 2 months**

**Automated Approach:**
- 1,000 products
- 1 image per product
- $0.10 per image (system cost amortized)
- 2 days timeline
- **Total: $100, 2 days**

**ROI:**
- 500x cost reduction
- 30x time reduction
- Enables rapid iteration and testing

### Competitive Advantage

**Brands that automate:**
- Refresh catalogs seasonally (not annually)
- Test creative variations at scale
- Localize campaigns without reshoots
- Respond to trends in days, not months

**Brands that don't:**
- Stuck with outdated visuals
- Limited A/B testing
- High creative costs
- Slow time-to-market

## 0.4 Why Brands Lose by Generating Images One by One

### The One-by-One Problem

**Manual Generation:**
```
Image 1 → Review → Iterate → Image 2 → Review → Iterate → ...
```

**Issues:**
1. **Inconsistency:** Each image is unique, no systematic approach
2. **Time:** Linear scaling (1 hour per image)
3. **Cost:** High per-unit cost
4. **Quality:** Variable, depends on individual execution
5. **Scalability:** Impossible to scale beyond small batches

### The System Approach

**Automated Generation:**
```
System → Batch → Review → Iterate System → Batch → ...
```

**Benefits:**
1. **Consistency:** Systematic approach ensures uniformity
2. **Time:** Parallel processing (100 images in same time as 1)
3. **Cost:** Amortized system cost
4. **Quality:** Systematic quality control
5. **Scalability:** Unlimited scale potential

### Real Example: E-commerce Catalog

**One-by-One Approach:**
- 500 products
- 1 designer, 1 hour per product
- 500 hours = 12.5 weeks
- Cost: $50,000
- Result: Inconsistent quality, outdated by launch

**System Approach:**
- 500 products
- 1 system, 2 minutes per product
- 16.7 hours = 2 days
- Cost: $500
- Result: Consistent quality, ready for launch

## 0.5 Understanding the Creative System Components

### Inputs

**What goes into the system:**
- Product data (SKU, name, description, attributes)
- Brand guidelines (colors, fonts, style)
- Art direction (moodboards, references)
- Constraints (dimensions, formats, channels)
- Briefs (campaign goals, target audience)

### Variants

**What the system generates:**
- Product variations (different angles, contexts)
- Style variations (different art directions)
- Channel variations (different formats, aspect ratios)
- Localization variations (different languages, regions)
- Seasonal variations (different themes, colors)

### Constraints

**What limits the system:**
- Brand guidelines (must follow)
- Technical requirements (must meet)
- Legal requirements (must comply)
- Quality standards (must achieve)

### Repetition Points

**Where automation applies:**
- Product loop (same system, different products)
- Variant loop (same product, different styles)
- Channel loop (same creative, different formats)
- Localization loop (same creative, different languages)

## 0.6 Assignment: Deconstruct a Past Campaign

### Objective

Deconstruct a past campaign into its component parts to understand:
- What inputs were needed
- What variants were created
- What constraints were applied
- Where repetition occurred

### Instructions

1. **Select a Campaign**
   - Choose a recent e-commerce campaign
   - Should have multiple products and/or variations
   - Should have clear creative elements

2. **Map the Inputs**
   - List all product data used
   - Identify brand guidelines applied
   - Note art direction references
   - Document constraints (dimensions, formats)

3. **Identify Variants**
   - List all variations created
   - Categorize by type (product, style, channel, localization)
   - Count total variations

4. **Document Constraints**
   - Brand guidelines
   - Technical requirements
   - Legal/compliance requirements
   - Quality standards

5. **Find Repetition Points**
   - Where was the same process repeated?
   - What could have been automated?
   - What patterns emerge?
