## Assignment Index

### Module 0
**Assignment:** Deconstruct a past campaign into inputs, variants, constraints, and repetition points
- Identify all inputs in your campaign
- Map variant generation points
- List constraints and guardrails
- Find repetition opportunities

### Module 1
**Assignment:** Sketch your first creative system on paper
- One concept
- Multiple products
- Reusable structure

### Module 2
**Deliverable:** A reusable system prompt that outputs:
- Photorealistic visuals
- Brand-aligned aesthetics
- Non-caricatural representations

### Module 3
**Assignment:** Create:
- 1 moodboard-driven workflow
- 2 divergent art directions from the same catalog

### Module 4
**Assignment:** Improve one weak product output using:
- Better angles
- Better descriptions
- Better references

### Module 5
**Exercise:** Design a bundle system:
- Inputs: products
- Outputs: consistent visuals
- Loop logic

### Module 6
**Hands-on:** Run the same creative logic across:
- 10 products
- 50 products
- 1 full catalog

### Module 7
**Use Cases:** Apply to:
- Meta ads
- TikTok variations
- Seasonal storefront refresh
- Regional campaigns

### Module 8
**Final Project:** Build a full automated e-commerce creative system that:
- Generates multiple concepts
- Applies a fixed art direction
- Bundles products
- Loops across a catalog
- Outputs ready-to-use assets
