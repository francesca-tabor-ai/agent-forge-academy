## Lesson 6.2: Measuring Question Frequency and Abandonment

### Metrics

**Frequency Metrics**
- Questions per session
- Repeat questions
- Question categories
- Peak question times

**Abandonment Metrics**
- Conversation completion rate
- Abandonment points
- Time to abandonment
- Abandonment reasons

### Analysis Framework

```python
def analyze_chatbot_intelligence(conversations):
    """
    Analyze chatbot interactions for intelligence
    """
    intelligence = {
        'friction_points': identify_friction_points(conversations),
        'question_frequency': calculate_question_frequency(conversations),
        'abandonment_analysis': analyze_abandonment(conversations),
        'unmet_needs': detect_unmet_needs(conversations),
        'insights': generate_insights(conversations)
    }
    
    return intelligence
```
