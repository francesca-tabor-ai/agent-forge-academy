##  Technology Reference

### Algorithms Covered
- **COSMO** - Common Sense Mining (Module 1)
- **Rufus Architecture** - Generative shopping assistant (Module 1)
- **YOLOv3** - Object localization (Module 2)
- **Seq2Seq Models** - Query rewriting (Module 3)
- **PatternRAG** - Catalog guidance (Module 4)
- **ASPIRE** - Causal inference (Module 5)
- **DeepMMATE** - Multimodal classification (Module 5)

### Frameworks & Tools
- **LLMs** - Intent understanding, generation (Modules 1, 3, 4)
- **Computer Vision** - Visual search, feature extraction (Module 2)
- **NLP Libraries** - Review summarization, query processing (Module 3)
- **Graph Algorithms** - De-duplication, clustering (Modules 2, 5)
- **Causal Inference** - Logistics optimization (Module 5)
