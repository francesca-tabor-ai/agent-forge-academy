# Module 5: Reinforcement Learning for Trading

**Duration:** Week 5  
**Learning Objectives:**
- Understand RL fundamentals for trading
- Implement Q-learning and policy gradient methods
- Build multi-agent trading systems
- Design risk-aware RL strategies

---

## Lesson 5.1: RL Fundamentals

### Trading as RL Problem
- State: Market data, portfolio state
- Action: Buy, sell, hold
- Reward: Returns, Sharpe ratio
- Environment: Market simulator

### Algorithms
- Q-learning
- Deep Q-Networks (DQN)
- Policy gradients (PPO, A3C)
- Actor-Critic methods

---

## Lesson 5.2: Risk-Aware RL

### Reward Shaping
- Risk-adjusted returns
- Drawdown penalties
- Volatility constraints
- Position limits

### Multi-Objective RL
- Return vs. risk trade-off
- Constrained RL
- Multi-agent coordination

Build a reinforcement learning agent for algorithmic trading.

**Deliverables:**
- RL environment
- Trading agent
- Training pipeline
- Performance evaluation
