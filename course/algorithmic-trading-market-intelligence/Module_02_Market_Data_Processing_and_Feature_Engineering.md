# Module 2: Market Data Processing and Feature Engineering

**Duration:** Week 2  
**Learning Objectives:**
- **Process High-Frequency**: Process high-frequency market data
- **Extract Technical**: Apply extract technical indicators in relevant contexts
- **alternative data sources Integration**: Integrate alternative data sources
- **feature engineering Development**: Build feature engineering pipelines

---

## Lesson 2.1: High-Frequency Data Processing

### Data Sources
- Exchange feeds
- Market data providers (Bloomberg, Reuters)
- Free sources (Yahoo Finance, Alpha Vantage)
- Real-time streaming APIs

### Storage Solutions
- TimescaleDB for time-series
- InfluxDB for metrics
- Parquet files for historical data
- Redis for real-time caching

## Lesson 2.2: Technical Indicators

### Trend Indicators
- Moving averages (SMA, EMA)
- MACD
- ADX
- Bollinger Bands

### Momentum Indicators
- RSI
- Stochastic oscillator
- Momentum
- Rate of change

### Volume Indicators
- Volume-weighted average price (VWAP)
- On-balance volume (OBV)
- Accumulation/distribution
