# Mastering the AI Factory: AI-Native Software Delivery

## 📚 Course Overview

**Duration:** 7 weeks  
**Level:** Intermediate to Advanced  
**Time Commitment:** 8-10 hours per week  
**Prerequisites:** Software engineering experience, familiarity with AI/LLMs, Git/GitHub

## 📋 Course Modules

### [Module 1: Foundations of AI-Native Engineering](Module_01_Foundations_of_AI_Native_Engineering.md)
- The AI Development Spectrum: Levels 1-5 from AI-Assisted to AI-Native
- The Vision of the AI Factory: Integrated intelligent systems
- Productivity Goals: Achieving 10x gains through automated feature development

### [Module 2: Specification-First Methodology (SDD)](Module_02_Specification_First_Methodology_SDD.md)
- Defining Intent: Machine-parsable PRDs and specifications
- Algorithmic Verification: Given/when/then structures for deterministic testing
- OpenSpec and Spec-Kit: Toolkits for human-AI alignment

### [Module 3: Context Engineering & The Knowledge Fabric](Module_03_Context_Engineering_and_The_Knowledge_Fabric.md)
- Agent Experience (AX): Steering rules and context files
- Knowledge Registries: Tessl registries and MCP servers
- Retrieval-Augmented Generation (RAG): AI-native databases and multi-vector retrieval

### [Module 4: Agent Orchestration & Protocol Layers](Module_04_Agent_Orchestration_and_Protocol_Layers.md)
- Model Context Protocol (MCP): The "USB-C port" for AI
- Separation of Agentic Concerns: Specialized agents for planning, coding, and review
- Agent Swarm Management: TaskingAI, Claude Flow, and autonomous agent fleets

### [Module 5: Agentic DevOps & Operations](Module_05_Agentic_DevOps_and_Operations.md)
- SRE Agents: Autonomous detection, root-cause analysis, and auto-scaling
- AI-Enhanced CI/CD: Semantic code review and risk analysis
- Application Modernisation: Automated refactoring to cloud-native architectures

### [Module 6: Governance, Security & High-Assurance](Module_06_Governance_Security_and_High_Assurance.md)
- Network Sandboxing: Policy engines (Cedar, Warden) for agent request interception
- AI Evaluations (Evals): Statistical population tests for abstraction adherence
- Invariant Verification: Property-based testing for architectural bugs

### [Module 7: The Evolving Role of the Human Engineer](Module_07_The_Evolving_Role_of_the_Human_Engineer.md)
- Supervisor Workflow: Managing boundaries of trust and automerge decisions
- Audit and Forensics: Tracking AI authorship with Git AI
- The Manager-Agent Relationship: Coaching agents through iterative feedback
