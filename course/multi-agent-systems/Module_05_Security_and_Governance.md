# Module 5: Security and Governance

**Duration:** Weeks 6-7  
**Learning Objectives:**
- Understand agent security threats and mitigations
- Implement identity and access management
- Design data security controls
- Navigate compliance frameworks

## Topics Covered:

### 5.1 The Agent Security Landscape (2025)
- Novel threat vectors (prompt injection, model poisoning, memory poisoning)
- Attack surface analysis
- Real-world security incidents
- Security budget allocation (20-30%)

### 5.2 Identity and Access Management
- Agent identity frameworks (Microsoft Entra Agent ID)
- Authentication and token security
- RBAC implementation in Kubernetes
- Dynamic authorization policies

### 5.3 Data Security and Privacy
- Data in transit, at rest, and in use
- PII detection and masking
- Encryption strategies
- Compliance requirements (GDPR, SOC2)

### 5.4 Network Security
- Network policies in Kubernetes
- Service mesh for mTLS
- Egress control
- API gateway patterns

### 5.5 Governance Frameworks
- Agent 365 control plane (Microsoft)
- Agent lifecycle management
- Compliance standards: ISO 42001, NIST AI RMF, GDPR

### 5.6 Guardrails and Safety Controls
- Task adherence monitoring
- Prompt shields and injection protection
- Cost limits and loop detection
- Human-in-the-loop controls

### 5.7 Agent Registry and Discovery
- Shadow agent detection
- Agent registration and approval workflows

## Labs:
- Lab 6: Implement RBAC with network policies and secrets
- Lab 7: Build safety guardrails with approval gates
