# Module 4: Containerization and Deployment

**Duration:** Weeks 4-5  
**Learning Objectives:**
- Containerize agents with Docker best practices
- Deploy to Kubernetes from basics to advanced
- Use Terraform for infrastructure as code
- Leverage GKE Agent Sandbox features

## Topics Covered:

### 4.1 Containerization with Docker
- Agent containerization best practices
- Multi-stage builds and optimization
- Security scanning
- Development workflow with Docker Compose

### 4.2 Kubernetes Fundamentals for AI Agents
- Core concepts: Pods, Deployments, Services
- ConfigMaps and Secrets
- Resource management
- Health checks (liveness/readiness probes)

### 4.3 Advanced Kubernetes
- Namespaces and resource quotas
- Horizontal Pod Autoscaling (HPA)
- StatefulSets for stateful agents
- Persistent volumes

### 4.4 GKE Agent Sandbox (2025)
- AgentSandbox APIs for security and isolation
- Sub-second latency for isolated workloads
- Pod Snapshots for fast startup
- Container-optimized compute

### 4.5 Infrastructure as Code with Terraform
- Kubernetes cluster provisioning
- Network configuration
- Multi-cloud deployment patterns

## Labs:
- Lab 4: Deploy multi-agent system to local Kubernetes
- Lab 5: Production deployment to GKE/EKS/AKS with autoscaling
