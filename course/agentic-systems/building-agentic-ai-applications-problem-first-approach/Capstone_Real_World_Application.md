# Capstone: Apply Everything in a Real-World Capstone

**Duration:** Week 5 (Final Week)  
**Learning Objectives:**
- Apply problem-first approach to a real business problem
- Build an end-to-end agentic AI solution
- Integrate RAG, MCP, and multi-agent components
- Present your solution to 2000+ attendees including enterprise leaders, investors, and hiring managers

---

## Capstone Overview

### The Challenge

Work in small teams (2-4 people) to design and implement an end-to-end agentic AI solution for a real business problem. Your solution will be evaluated on:

1. **Problem Understanding** - Did you identify and understand a real business problem?
2. **Solution Design** - Is your solution appropriate and well-designed?
3. **Implementation** - Did you build a working system?
4. **Evaluation** - Did you evaluate your solution properly?
5. **Presentation** - Can you communicate your work effectively?

### The Three Iterations

You'll build an agentic search system across three iterations:

**Iteration 1: Foundation**
- Basic agentic search with RAG
- Simple evaluation
- Proof of concept

**Iteration 2: Enhancement**
- Add multi-agent coordination
- Integrate MCP protocols
- Improve evaluation

**Iteration 3: Production-Ready**
- Optimize for production
- Add guardrails and monitoring
- Final evaluation and presentation

## Capstone Requirements

### Problem Selection

**Choose a Real Business Problem:**

✅ **Good Problems:**
- Clear business value
- Appropriate for agentic AI
- Measurable success criteria
- Realistic scope

❌ **Avoid:**
- Toy problems or demos
- Problems better solved with simple automation
- Problems without clear value
- Overly complex problems

**Examples:**
- Customer support automation
- Research assistant for specific domain
- Document analysis and summarization
- Multi-step data analysis
- Content generation with quality control

5. **Evaluation Framework**

## Iteration 1: Foundation

### Goals

- Build basic agentic search system
- Integrate RAG
- Implement basic evaluation
- Create proof of concept

### Requirements

1. **Agentic Search System**
   - Agent that can search and retrieve information
   - Basic planning and reflection
   - Simple tool use

2. **RAG Integration**
   - Knowledge base (at least 100 documents)
   - Retrieval system
   - Context management

3. **Basic Evaluation**
   - Test dataset (20-30 queries)
   - Basic metrics (accuracy, latency)
   - Initial results

4. **Documentation**
   - System overview
   - Setup instructions
   - Usage examples

### Deliverables

- Working code
- Demo video (5 minutes)
- Evaluation results
- Documentation

---

## Iteration 2: Enhancement

### Goals

- Add multi-agent coordination
- Integrate MCP/A2A protocols
- Enhance evaluation
- Improve system performance

### Requirements

1. **Multi-Agent System**
   - At least 2 specialized agents
   - Coordination between agents
   - Clear agent roles

2. **Protocol Integration**
   - MCP for tools OR A2A for communication
   - Standardized interfaces
   - Error handling

3. **Enhanced Evaluation**
   - Expanded test dataset (50+ queries)
   - Additional metrics
   - Failure mode analysis
   - Performance improvements

4. **Improvements**
   - Better accuracy
   - Optimized latency
   - Enhanced functionality

### Deliverables

- Updated code
- Updated demo video
- Enhanced evaluation results
- Architecture documentation

## Final Presentation

### Format

- **Duration:** 10 minutes presentation + 5 minutes Q&A
- **Audience:** 2000+ attendees (enterprise leaders, investors, hiring managers)
- **Format:** Live presentation with demo

### Presentation Structure

1. **Problem (2 min)**
   - What problem are you solving?
   - Why does it matter?
   - What's the business value?

2. **Solution (3 min)**
   - How does your solution work?
   - Key components
   - Architecture overview

3. **Demo (3 min)**
   - Live demo
   - Show key features
   - Demonstrate value

4. **Results (2 min)**
   - Evaluation results
   - Performance metrics
   - Business impact

5. **Lessons Learned (1 min)**
   - What worked well?
   - What would you do differently?
   - Key takeaways

### Q&A Preparation

Be prepared to answer:
- Technical questions about your implementation
- Questions about business value
- Questions about scalability
- Questions about alternatives
- Questions about next steps

## Key Takeaways

1. **Start with the problem** - Deep understanding is essential

2. **Iterate systematically** - Each iteration builds on the previous

3. **Evaluate continuously** - Don't wait until the end

4. **Think production** - Build for real use, not just demos

5. **Communicate effectively** - Presentation matters as much as code
