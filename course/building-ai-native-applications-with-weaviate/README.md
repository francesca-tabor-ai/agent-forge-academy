# Building AI-Native Applications with Weaviate

## Course Overview

**Duration:** 8 weeks (or 12 weeks with projects expanded)  
**Level:** Intermediate (suitable for advanced beginners with Python knowledge)  
**Time Commitment:** 8-10 hours per week  
**Prerequisites:** Python programming, basic understanding of machine learning concepts, familiarity with REST APIs, (optional) intro knowledge of embeddings and LLMs

---

## What You'll Master

By completing this course, you will be able to:

- Explain vector databases and similarity search concepts
- Design schemas and data models in Weaviate
- Ingest, index, and query multimodal data
- Implement semantic and hybrid search
- Build RAG pipelines using Weaviate + LLMs
- Deploy and scale Weaviate in production environments

---

## Course Modules

### [Module 1: Vector Databases & AI-Native Architecture](Module_01_Vector_Databases_AI_Native_Architecture.md)
- Why vector databases exist
- Embeddings and similarity search
- AI-native application architecture
- Overview of Weaviate features
- **Lab:** Install Weaviate locally (Docker), explore the Weaviate Console

### [Module 2: Weaviate Core Concepts](Module_02_Weaviate_Core_Concepts.md)
- Objects, classes, properties
- Collections & schema design
- Vectorizers vs. user-provided vectors
- Distance metrics (cosine, dot, L2)
- **Lab:** Create schemas programmatically, insert and retrieve basic objects

### [Module 3: Data Ingestion & Indexing](Module_03_Data_Ingestion_Indexing.md)
- Batch ingestion
- HNSW indexing fundamentals
- Consistency and replication
- Handling large-scale datasets
- **Lab:** Ingest a document corpus, benchmark query performance

### [Module 4: Semantic & Hybrid Search](Module_04_Semantic_Hybrid_Search.md)
- nearVector, nearText, and nearObject
- Keyword vs semantic search
- Hybrid search and alpha tuning
- Filters and metadata constraints
- **Lab:** Build a semantic document search engine, compare keyword vs hybrid results

### [Module 5: Modules & Integrations](Module_05_Modules_Integrations.md)
- Text, image, and multimodal modules
- OpenAI, Cohere, Hugging Face integrations
- Custom embedding pipelines
- **Lab:** Plug in an external embedding model, store and query multimodal data

### [Module 6: Retrieval-Augmented Generation (RAG)](Module_06_Retrieval_Augmented_Generation_RAG.md)
- RAG design patterns
- Context chunking strategies
- Prompt engineering for retrieval
- Evaluation of RAG outputs
- **Lab:** Build a RAG chatbot using Weaviate + an LLM

### [Module 7: Scaling, Security & Deployment](Module_07_Scaling_Security_Deployment.md)
- Horizontal scaling and sharding
- Authentication and authorization
- Weaviate Cloud vs self-hosted
- Monitoring and observability
- **Lab:** Deploy Weaviate on Kubernetes or cloud VM

### [Module 8: Capstone Project](Module_08_Capstone_Project.md)
- Enterprise semantic document search
- AI-powered customer support bot
- Multimodal product recommendation system
- Knowledge graph + vector search hybrid app
- **Deliverables:** Architecture diagram, working demo, technical report
