## 3.1 The Question Gap

### What Buyers Ask AI vs. What You Think They Ask

**Traditional Assumption:**
- Buyers ask: "What is this product?"
- Buyers want: Basic features and benefits
- Buyers need: Persuasive marketing copy

**AI Reality:**
- Buyers ask: "Is this good for X specific use case?"
- Buyers want: Objective comparisons and constraints
- Buyers need: Evidence-based decision support

### The Blind Spot

Most brands don't know:
- What questions buyers actually ask AI
- How AI answers those questions
- Whether their content addresses those questions
- What gaps exist between questions and content

## 3.2 Rufus Question Patterns

### Common Rufus Question Types

**1. Use Case Fit Questions**
- "Is this good for [specific use case]?"
- "Can I use this for [specific scenario]?"
- "Will this work for [specific need]?"

**Example:**
- "Is this laptop good for video editing?"
- "Can I use these headphones for running?"
- "Will this work with my iPhone?"

**2. Comparison Questions**
- "How does this compare to [competitor]?"
- "Is this better than [alternative]?"
- "What's the difference between this and [other product]?"

**Example:**
- "How does this compare to the MacBook Pro?"
- "Is this better than the Sony WH-1000XM5?"
- "What's the difference between this and the competitor model?"

**3. Constraint Questions**
- "What are the limitations?"
- "What doesn't this do well?"
- "Who shouldn't buy this?"

**Example:**
- "What are the limitations of this product?"
- "What doesn't this laptop do well?"
- "Who shouldn't buy these headphones?"

**4. Problem Questions**
- "What are common issues?"
- "Does this break easily?"
- "What should I watch out for?"

**Example:**
- "What are common issues with this product?"
- "Does this break easily?"
- "What should I watch out for when buying this?"

**5. Value Questions**
- "Is this worth the price?"
- "Is there a better value alternative?"
- "When does this go on sale?"

**Example:**
- "Is this worth $200?"
- "Is there a better value alternative?"
- "When does this typically go on sale?"

### How Rufus Answers

**Rufus synthesizes answers from:**
1. Product specifications
2. Customer reviews (objection patterns)
3. Q&A sections
4. Comparison data
5. Third-party sources

**Answer Structure:**
- Direct answer to question
- Evidence supporting answer
- Constraints or limitations
- Comparison context when relevant

## 3.3 Review-Based Objection Mining

### Extracting Questions from Reviews

**Review Question Patterns:**

**1. Pre-Purchase Questions (in negative reviews)**
- "I wish I had known X before buying"
- "If you need Y, this isn't for you"
- "I thought this would do Z, but it doesn't"

**Example:**
- "I wish I had known the battery life is only 4 hours"
- "If you need noise cancellation, this isn't for you"
- "I thought this would work with my old phone, but it doesn't"

**2. Post-Purchase Questions (in positive reviews)**
- "I was worried about X, but it's actually fine"
- "I wasn't sure if this would work for Y, but it does"
- "I thought Z would be a problem, but it's not"

**Example:**
- "I was worried about comfort, but it's actually fine for long sessions"
- "I wasn't sure if this would work for my use case, but it does"
- "I thought the size would be a problem, but it's not"

**3. Comparison Questions (in reviews)**
- "I had X before, this is better/worse because Y"
- "Compared to Z, this does A better but B worse"

**Example:**
- "I had the previous model, this is better because of the battery"
- "Compared to the competitor, this has better sound but worse comfort"

### Objection-to-Question Mapping

**Common Objections → Questions Buyers Ask:**

**Durability Objections:**
- "Breaks easily" → "Is this durable?"
- "Poor build quality" → "Will this last?"

**Performance Objections:**
- "Doesn't work as advertised" → "Does this actually do X?"
- "Slower than expected" → "How fast is this really?"

**Use Case Mismatches:**
- "Not good for X" → "Is this good for X?"
- "Doesn't work with Y" → "Will this work with Y?"

**Value Objections:**
- "Not worth the price" → "Is this worth the price?"
- "Better alternatives available" → "Is there a better alternative?"

## 3.4 Forum Skepticism and Edge-Case Use

### Forum Question Patterns

**1. Skeptical Questions**
- "Is the marketing claim about X actually true?"
- "Has anyone verified Y?"
- "What's the catch with Z?"

**Example:**
- "Is the battery life claim actually true?"
- "Has anyone verified the noise cancellation works?"
- "What's the catch with this product?"

**2. Edge Case Questions**
- "Will this work for [unusual use case]?"
- "Has anyone tried X with Y?"
- "What happens if I do Z?"

**Example:**
- "Will this work for left-handed users?"
- "Has anyone tried this with Windows 11?"
- "What happens if I use this in extreme temperatures?"

**3. Technical Deep Dive Questions**
- "How does X actually work?"
- "What's the technical difference between Y and Z?"
- "Can I modify this to do A?"

**Example:**
- "How does the noise cancellation actually work?"
- "What's the technical difference between this and the competitor?"
- "Can I modify this to work with my setup?"

**4. Failure Mode Questions**
- "What are the common failure modes?"
- "What breaks first?"
- "How long until X fails?"

**Example:**
- "What are the common failure modes?"
- "What breaks first on this product?"
- "How long until the battery degrades?"

### Why Forum Questions Matter

**1. Reveal Blind Spots**
- Questions you never thought of
- Use cases you didn't consider
- Edge cases you didn't anticipate

**2. Expose Marketing Gaps**
- Claims that aren't verified
- Questions your content doesn't answer
- Skepticism about your messaging

**3. Identify High-Value Content**
- Questions that indicate purchase intent
- Questions that reveal decision factors
- Questions that show information needs

## 3.5 Pre-Purchase vs Post-Purchase AI Questions

### Pre-Purchase Questions

**Purpose:** Decision support before buying

**Question Types:**
1. **Fit Questions:** "Is this right for me?"
2. **Comparison Questions:** "Is this better than alternatives?"
3. **Constraint Questions:** "What are the limitations?"
4. **Value Questions:** "Is this worth it?"

**Content Needs:**
- Use case clarity
- Comparison data
- Constraint acknowledgment
- Value proposition evidence

### Post-Purchase Questions

**Purpose:** Problem-solving after buying

**Question Types:**
1. **Setup Questions:** "How do I set this up?"
2. **Usage Questions:** "How do I use X feature?"
3. **Problem Questions:** "Why isn't this working?"
4. **Optimization Questions:** "How do I get the best results?"

**Content Needs:**
- Setup instructions
- Feature documentation
- Troubleshooting guides
- Optimization tips

### The Content Gap

**Pre-Purchase Content:**
- Most brands have this (marketing copy)
- But often lacks: constraints, comparisons, evidence

**Post-Purchase Content:**
- Many brands lack this
- But critical for: reducing returns, building trust, generating reviews

## 3.6 Building Your AI Product Question Repository

### Question Collection Methods

**1. Direct AI Interaction**
- Ask AI assistants about your products
- Note what questions AI asks you
- Track how AI answers questions
- Identify answer gaps

**2. Review Mining**
- Extract questions from review language
- Map objections to questions
- Identify question patterns
- Track question frequency

**3. Forum Monitoring**
- Monitor Reddit, forums, social media
- Extract questions about your products
- Note edge cases and skepticism
- Track emerging questions

**4. Q&A Analysis**
- Analyze marketplace Q&A sections
- Extract common questions
- Identify unanswered questions
- Track question trends

### Question Categorization

**By Question Type:**
- Use case fit
- Comparison
- Constraint
- Problem
- Value
- Technical
- Setup/Usage

**By Purchase Stage:**
- Pre-purchase (decision support)
- Post-purchase (problem-solving)

**By Frequency:**
- High frequency (must answer)
- Medium frequency (should answer)
- Low frequency (nice to answer)

**By Answer Quality:**
- Well-answered (content exists)
- Partially answered (content incomplete)
- Unanswered (content gap)

## Lab 3: AI Product Question Repository

### Objective
Systematically extract real buyer questions surfaced by AI and identify coverage gaps.

### Tasks

**Task 1: AI Interaction Mining**
For 3 flagship products:
1. Ask AI assistants (ChatGPT, Claude, Perplexity) about each product
2. Note what questions AI asks you
3. Track how AI answers questions
4. Identify questions AI can't answer well

**Task 2: Review Question Extraction**
For each product:
1. Extract questions from negative reviews ("I wish I had known X")
2. Extract questions from positive reviews ("I was worried about X")
3. Map objections to questions
4. Categorize questions by type

**Task 3: Forum Question Collection**
For each product:
1. Search Reddit, forums for product mentions
2. Extract questions from discussions
3. Note edge cases and skepticism
4. Identify technical deep-dive questions

**Task 4: Coverage Gap Analysis**
For each question:
1. Can your current content answer it? (Yes/No/Partially)
2. What content would answer it?
3. Priority level (High/Medium/Low)
4. Question frequency estimate

### Deliverables
1. AI Interaction Mining Report
2. Review Question Extraction (categorized)
3. Forum Question Collection
4. Coverage Gap Analysis by SKU

### Evaluation Criteria
- Comprehensive question collection (30%)
- Accurate categorization (30%)
- Actionable gap analysis (40%)
