##  Technology Reference

### Core Concepts Covered
- **Reasoning Experience (RX)** - Machine-first design (Modules 1, 3, 5)
- **Ontologies** - Entity definitions (Module 2)
- **Taxonomies** - Controlled vocabularies (Module 2)
- **Evidence Graphs** - Knowledge structure (Module 2)
- **Intent-Driven APIs** - Goal-oriented interfaces (Module 3)
- **Uncertainty Encoding** - Confidence and validity (Module 3)
- **State Machines** - Safe action patterns (Module 4)
- **Action Boundaries** - Safety gates (Module 4)
- **Presence Metrics** - Visibility measurement (Module 5)
- **Evidence Telemetry** - Data source tracking (Module 5)
- **Drift Detection** - Knowledge decay monitoring (Module 6)
- **Governance Frameworks** - Quality ownership (Module 6)

### Tools & Standards
- **JSON-LD** - Structured data (Modules 2, 3)
- **Schema.org** - Semantic markup (Modules 2, 3)
- **REST/GraphQL** - API design (Module 3)
- **State Machines** - Action patterns (Module 4)
- **Telemetry Systems** - Observability (Module 5)
- **Version Control** - Knowledge management (Module 6)
