# Engineering for Machine Judgment (RX)

##  Course Overview

**Duration:** 6 weeks (7 total with final project)  
**Level:** Intermediate to Advanced  
**Time Commitment:** 6-8 hours per week  
**Prerequisites:** Web development basics, understanding of AI/LLMs

---

##  What You'll Master

By completing this course, you will be able to:

 Design websites optimized for AI intermediaries (ChatGPT, Amazon Rufus, Perplexity)  
 Build structured knowledge systems that machines can reliably understand  
 Create intent-driven APIs that enable safe machine actions  
 Implement safety boundaries and governance for AI-operated systems  
 Measure and optimize participation in AI judgment processes  
 Navigate the shift from User Experience (UX) to Reasoning Experience (RX)  

---

##  Course Modules

### [Module 1: The Paradigm Shift – From Search to Judgment](Module_01_The_Paradigm_Shift.md)
- The End of the Interface: How discovery moved into AI reasoning
- Ranking vs. Judgment: Understanding AI selectivity and justification
- From UX to RX: Shifting from clicks to machine comprehension
- **Exercise 1.1:** Analyze AI intermediary responses
- **Exercise 1.2:** Map traditional UX vs RX patterns
- **Exercise 1.3:** Design RX-first content structure

### [Module 2: Knowledge as Infrastructure](Module_02_Knowledge_as_Infrastructure.md)
- Ontology Before Intelligence: Building clear entity definitions
- Killing Ambiguity with Taxonomies: Controlled vocabularies
- The Evidence Graph: Separating facts, patterns, and anecdotes
- **Exercise 2.1:** Build domain ontology
- **Exercise 2.2:** Create taxonomy for your domain
- **Exercise 2.3:** Design evidence graph structure

### [Module 3: Designing for Machine-First Interoperability](Module_03_Designing_for_Machine_First_Interoperability.md)
- Intent-Driven APIs: Moving beyond CRUD to goal-oriented interfaces
- Explicit Uncertainty Encoding: Confidence levels and validity windows
- Legibility Over Persuasion: Machine-verifiable content design
- **Exercise 3.1:** Design intent-driven API
- **Exercise 3.2:** Implement uncertainty encoding
- **Exercise 3.3:** Create machine-legible content

### [Module 4: Systems That Can Act Safely](Module_04_Systems_That_Can_Act_Safely.md)
- State Machines vs. Chat: Discrete states for safe actions
- Action Boundaries & Refusal: Confirmation and refusal patterns
- Outcome Loops: Closing policy-to-reality gaps
- **Exercise 4.1:** Design state machine for actions
- **Exercise 4.2:** Implement action boundaries
- **Exercise 4.3:** Create outcome feedback loop

### [Module 5: Visibility & Observability (The New Funnel)](Module_05_Visibility_and_Observability.md)
- Presence, Citation, and Influence: Measuring participation in judgment
- Evidence Telemetry: Tracking data source retrieval and overrides
- Traceability & Defensibility: Reasoning step records
- **Exercise 5.1:** Implement presence tracking
- **Exercise 5.2:** Build evidence telemetry system
- **Exercise 5.3:** Create traceability logs

### [Module 6: Governance, Drift, and Power](Module_06_Governance_Drift_and_Power.md)
- Managing Silent Decay: Detecting knowledge drift and aging
- Institutional Reform: Owning knowledge quality
- Ethics as Enforced Governance: Embedded refusal patterns
- **Exercise 6.1:** Design drift detection system
- **Exercise 6.2:** Create governance framework
- **Exercise 6.3:** Implement ethical boundaries
