# Prediction OS: Applied Machine Learning for Business

##  Course Overview

**Duration:** 8–10 weeks (cohort-based or self-paced)  
**Level:** Intermediate → Advanced  
**Time Commitment:** 8-10 hours per week  
**Prerequisites:** Python, basic statistics, SQL, understanding of machine learning fundamentals

---

##  What You'll Master

By completing this course, you will be able to:

✅ Frame business problems as ML problems that matter  
✅ Engineer features that scale and generalize  
✅ Build, evaluate, and iterate predictive models  
✅ Translate model outputs into **actions, policies, and value**  
✅ Design and operate a **Prediction Operating System**  
✅ Embed predictions into decision-making systems

---

##  Course Modules

### [Module 1: Problem Framing for Machine Learning](Module_01_Problem_Framing_for_Machine_Learning.md)
**Theme:** *What should we predict — and why?*
- Prediction vs explanation vs optimization
- Mapping business decisions to ML problems
- Defining targets, labels, and prediction horizons
- Choosing the right ML approach
- Common framing failures
- **Hands-on:** Convert business questions into ML problems

### [Module 2: Data Understanding & Feature Thinking](Module_02_Data_Understanding_and_Feature_Thinking.md)
**Theme:** *Garbage in, garbage out — but smarter*
- Understanding data-generating processes
- Static vs dynamic features
- Behavioral, temporal, and aggregate features
- Feature leakage and future data contamination
- **Hands-on:** Exploratory feature analysis and leak detection

### [Module 3: Feature Engineering at Scale](Module_03_Feature_Engineering_at_Scale.md)
**Theme:** *From notebook features to production features*
- Time-aware feature engineering
- Rolling windows, decay functions, and recency
- Aggregations across users, products, and events
- Offline vs online features
- **Hands-on:** Build time-based features for churn, demand, LTV

### [Module 4: Predictive Modeling Patterns](Module_04_Predictive_Modeling_Patterns.md)
**Theme:** *Choosing the right model for the job*
- Baselines first: rules & simple models
- Tree-based models (GBMs, Random Forests)
- Linear models & regularization
- Time-series models (ARIMA, Prophet, ML-based)
- When (and when not) to use deep learning
- **Hands-on:** Train and compare models for churn, demand, LTV

### [Module 5: Model Evaluation, Bias & Stability](Module_05_Model_Evaluation_Bias_and_Stability.md)
**Theme:** *Does the model actually work — and for whom?*
- Choosing the right evaluation metrics
- Offline vs online evaluation
- Segment-level performance analysis
- Bias, fairness, and unintended consequences
- Model robustness and temporal stability
- **Hands-on:** Evaluate models across segments, time, distributions

### [Module 6: From Prediction to Decision](Module_06_From_Prediction_to_Decision.md)
**Theme:** *Predictions don't create value — decisions do*
- Score thresholds & decision policies
- Cost-sensitive modeling
- Ranking vs classification
- Uplift vs propensity modeling (intro)
- Human-in-the-loop decisioning
- **Hands-on:** Translate churn scores into retention actions

### [Module 7: Productionization & Feedback Loops](Module_07_Productionization_and_Feedback_Loops.md)
**Theme:** *Keeping models alive*
- Batch vs real-time prediction
- Monitoring model performance & drift
- Retraining strategies
- Data quality checks
- Collaboration with ML Engineers
- **Hands-on:** Design a monitoring plan

### [Module 8: Communicating ML Impact](Module_08_Communicating_ML_Impact.md)
**Theme:** *Winning trust across stakeholders*
- Explaining models to non-technical audiences
- Visualizing prediction outputs
- Communicating uncertainty
- Aligning with Product & Business teams
- ML storytelling for leadership
- **Hands-on:** Present model results as business recommendation

### [Capstone Project: Build a Prediction OS](Module_09_Capstone_Project_Build_a_Prediction_OS.md)
**Theme:** *End-to-end applied ML system*
- Frame a business problem
- Engineer features
- Train predictive models
- Evaluate bias & stability
- Translate predictions into decisions
- **Deliverables:** Problem framing, feature pipeline, model report, decision policy, impact summary
