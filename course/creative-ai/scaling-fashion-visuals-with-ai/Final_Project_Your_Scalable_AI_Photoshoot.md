# Final Project: Your Scalable AI Photoshoot
**Build one complete AI agent that generates 50+ on-brand visuals**

**Duration:** 2-3 weeks  
**Project Type:** Capstone Project  
**Weight:** 30% of course grade

---

## Project Overview

Build a complete, production-ready AI agent system that can generate 50+ on-brand fashion visuals automatically. This project integrates all concepts from the course into a single, scalable system.

---

## Project Requirements

### Core Requirements

Your AI agent must:

1. **Generate 50+ on-brand visuals**
   - Process at least 50 products
   - Maintain brand consistency
   - Meet quality standards
   - Ready for production use

2. **Use batch inputs**
   - Accept multiple products at once
   - Process in batches
   - Handle errors gracefully
   - Track progress

3. **Export assets automatically**
   - Automatic export after generation
   - Organized file structure
   - Multiple format support
   - Cloud storage integration (optional)

4. **Be production-ready**
   - Documented workflow
   - Reusable template
   - Quality control process
   - Troubleshooting guide
