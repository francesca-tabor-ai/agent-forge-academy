# Capstone Project: Build an Insight OS

**Duration:** Weeks 7-8  
**Theme:** *End-to-end real-world simulation*

**Learning Objectives:**
- Apply all course concepts in a comprehensive project
- Build a complete Insight Operating System
- Demonstrate ability to work through the full analytics lifecycle
- Present insights in an executive-style review
- Showcase skills gained throughout the course

---

## Project Overview

### Objective

Build a complete Insight Operating System for a simulated business scenario. This capstone project integrates all concepts from the course into a real-world simulation.

### Project Structure

The capstone is divided into five phases, each building on the previous:

1. **Phase 1: KPI Framework** (Week 7, Days 1-2)
2. **Phase 2: SQL Analysis** (Week 7, Days 3-4)
3. **Phase 3: Dashboard Design** (Week 7, Days 5-6)
4. **Phase 4: Root-Cause Investigation** (Week 8, Days 1-3)
5. **Phase 5: Executive Communication** (Week 8, Days 4-5)

### Business Scenario

You are a data analyst at **TechFlow**, a SaaS company that provides project management software. The company has been growing rapidly but is experiencing some challenges:

- Revenue growth has slowed
- Customer churn has increased
- Product team is unsure which features drive retention
- Executive team needs better visibility into business performance

Your task is to build an Insight OS that helps TechFlow understand what's happening and why, enabling data-driven decisions.

### Available Data

You'll have access to simulated datasets including:

- **Users:** User signups, profiles, segments
- **Events:** User actions, feature usage, engagement
- **Subscriptions:** Subscription data, plans, billing
- **Support:** Support tickets, resolution times
- **Marketing:** Campaigns, channels, attribution

## Phase 1: KPI Framework

### Objective

Define a decision-aligned KPI framework for TechFlow.

### Tasks

**Task 1.1: Business Context Analysis (2 hours)**
- Understand TechFlow's business model
- Identify key business questions
- Document decision-making process
- Identify stakeholders and their needs

**Task 1.2: North Star Metric Selection (2 hours)**
- Identify candidate North Star metrics
- Evaluate each against North Star criteria
- Select the North Star metric
- Justify your selection

**Task 1.3: KPI Tree Construction (3 hours)**
- Build KPI tree breaking down North Star
- Identify leading and lagging indicators
- Map operational metrics
- Validate tree structure

**Task 1.4: Metric Anti-Pattern Review (1 hour)**
- Review all metrics for anti-patterns
- Identify and fix any issues
- Document improvements

### Deliverables

- Business context document (2 pages)
- North Star metric selection with justification (1 page)
- KPI tree diagram with annotations
- Metric catalog (initial version)

### Evaluation Criteria

- **Business Alignment (30%):** KPIs answer business questions
- **North Star Quality (25%):** Appropriate North Star selected
- **KPI Tree Structure (25%):** Logical, complete, actionable
- **Anti-Pattern Awareness (20%):** No anti-patterns, well-designed

---

## Phase 2: SQL Analysis

### Objective

Write production-grade SQL queries to analyze TechFlow's business performance.

### Tasks

**Task 2.1: Time-Series Analysis (2 hours)**
- Analyze revenue trends over time
- Calculate growth rates (MoM, YoY)
- Identify trends and patterns
- Create summary statistics

**Task 2.2: Cohort Analysis (3 hours)**
- Create user cohorts by signup month
- Calculate cohort retention rates
- Analyze cohort revenue
- Compare cohorts over time

**Task 2.3: Funnel Analysis (2 hours)**
- Map user journey (signup → activation → subscription)
- Calculate conversion rates at each step
- Identify drop-off points
- Segment by relevant dimensions

**Task 2.4: Performance Analysis (2 hours)**
- Calculate key metrics from KPI tree
- Use window functions for comparisons
- Create summary reports
- Validate data quality

### Deliverables

- SQL query file with all analyses
- Results summary document
- Data quality assessment
- Performance optimization notes

### Evaluation Criteria

- **Query Correctness (40%):** Accurate results, proper logic
- **SQL Best Practices (30%):** Clean code, efficient queries
- **Analysis Completeness (20%):** All required analyses completed
- **Documentation (10%):** Clear comments, assumptions documented

## Phase 3: Dashboard Design

### Objective

Design dashboards that drive action for different audiences at TechFlow.

### Tasks

**Task 3.1: Executive Dashboard (3 hours)**
- Design executive summary dashboard
- Select 5-7 key strategic metrics
- Create clear visualizations
- Add context and trends
- Include key insights section

**Task 3.2: Product Dashboard (3 hours)**
- Design product performance dashboard
- Focus on feature usage and engagement
- Include funnel analysis
- Add segmentation capabilities
- Show actionable insights

**Task 3.3: Operational Dashboard (2 hours)**
- Design operational monitoring dashboard
- Include real-time metrics
- Add alerts and status indicators
- Show performance trends
- Enable quick issue identification

### Deliverables

- 3 dashboard designs (mockups or working dashboards)
- Dashboard documentation
- Design rationale document
- User guide (brief)

### Evaluation Criteria

- **Audience Alignment (30%):** Appropriate for each audience
- **Visual Design (25%):** Clear, professional, effective
- **Signal vs Noise (25%):** Focused on what matters
- **Actionability (20%):** Drives decisions and actions

---

## Phase 4: Root-Cause Investigation

### Objective

Investigate a business issue and identify root causes.

### Tasks

**Task 4.1: Issue Identification (1 hour)**
- Review business performance data
- Identify significant issues or anomalies
- Prioritize issues for investigation
- Select one issue for deep dive

**Task 4.2: Hypothesis Generation (2 hours)**
- Generate multiple hypotheses for the issue
- Prioritize hypotheses by likelihood
- Plan investigation approach
- Identify data needed

**Task 4.3: Investigation Execution (4 hours)**
- Perform drill-down analysis
- Use segmentation to identify patterns
- Apply diagnostic techniques
- Test hypotheses with data
- Distinguish correlation from causation

**Task 4.4: Root Cause Identification (2 hours)**
- Identify root cause(s)
- Validate with evidence
- Quantify impact
- Assess confidence level
- Document findings

### Deliverables

- Investigation report (5-7 pages)
- Root-cause narrative
- Supporting analysis and evidence
- Confidence assessment

### Evaluation Criteria

- **Investigation Depth (40%):** Thorough analysis, multiple angles
- **Root Cause Accuracy (30%):** Correct root cause identified
- **Evidence Quality (20%):** Strong evidence, proper validation
- **Narrative Quality (10%):** Clear, compelling explanation

## Phase 5: Executive Communication

### Objective

Communicate insights effectively to executive audience.

### Tasks

**Task 5.1: Executive Brief (3 hours)**
- Create one-page executive brief
- Frame insights for executives
- Include recommendations
- Add confidence levels
- Make it actionable

**Task 5.2: Decision Memo (2 hours)**
- Write decision memo for key recommendation
- Include options and analysis
- Provide clear recommendation
- Address risks and considerations
- Include implementation plan

**Task 5.3: Presentation Preparation (2 hours)**
- Create executive presentation (10-15 slides)
- Structure as data story
- Prepare for Q&A
- Practice delivery
- Time presentation (10-12 minutes)

**Task 5.4: Executive Review (1 hour)**
- Present to mock executive panel
- Handle questions and pushback
- Demonstrate confidence and clarity
- Show business impact focus

### Deliverables

- One-page executive brief
- Decision memo (2 pages)
- Executive presentation (slides)
- Presentation delivery (recorded or live)
- Q&A handling notes

### Evaluation Criteria

- **Executive Framing (30%):** Appropriate for audience
- **Story Structure (25%):** Clear narrative, compelling
- **Recommendations (25%):** Actionable, specific, prioritized
- **Communication Quality (20%):** Clear, confident, professional
