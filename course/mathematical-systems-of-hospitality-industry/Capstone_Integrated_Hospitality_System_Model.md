# Capstone: Integrated Hospitality System Model

## Introduction

This capstone module integrates all course concepts into a comprehensive mathematical model of a hospitality operation. Students build a complete system covering demand, pricing, capacity, staffing, service levels, and customer value.

## Learning Objectives

- Synthesize mathematical concepts across all modules
- Build integrated hospitality system model
- Integrate demand forecasting, pricing, capacity, staffing, and customer value
- Make strategic recommendations
- Create mathematically defensible hospitality strategy

## Capstone Project Framework

### Project Structure

**1. System Definition**
- Define hospitality operation (hotel, restaurant, resort, platform)
- Identify key metrics
- Map data sources

**2. Component Development**
- Demand forecasting (Module 4)
- Pricing and revenue management (Modules 2, 3)
- Operations and queues (Module 5)
- Cost structures (Module 6)
- Customer lifetime value (Module 7)
- Experience measurement (Module 8)
- Data science applications (Module 9)
- Sustainability (Module 10)
- Systems thinking (Module 11)

**3. Integration**
- Connect components
- Calibrate models
- Validate assumptions

**4. Analysis**
- Base case simulation
- Scenario analysis
- Sensitivity analysis

**5. Recommendations**
- Strategic insights
- Optimization opportunities
- Implementation plan

## Integration Requirements

### Demand Forecasting

**Model:**
```
Demand(t) = f(Trend, Seasonality, Events, Price, ...)
```

**Integration:**
```
Demand → Pricing → Revenue
Demand → Staffing → Service
Demand → Capacity → Utilization
```

### Pricing and Capacity

**Pricing:**
```
Price = f(Demand_forecast, Inventory, Competitors, ...)
```

**Capacity:**
```
Capacity = Fixed
Utilization = Demand / Capacity
```

**Optimization:**
```
Maximize: Revenue
Subject to: Capacity_constraints
```

### Staffing and Service Levels

**Staffing:**
```
Staff = f(Demand_forecast, Service_level_target, ...)
```

**Service:**
```
Service_quality = f(Staffing, Training, Investment)
```

**Cost:**
```
Cost = f(Staffing, Operations, Service_level)
```

### Customer Value

**CLV:**
```
CLV = f(Revenue, Retention, Service_quality, ...)
```

**Integration:**
```
Service_quality → Satisfaction → Retention → CLV
Pricing → Revenue → CLV
```
