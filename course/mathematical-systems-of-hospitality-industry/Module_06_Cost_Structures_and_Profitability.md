# Module 6: Cost Structures & Profitability

## Introduction

Understanding cost structures is essential for profitability. This module covers fixed vs. variable costs, contribution margins, break-even analysis, and operating leverage.

## Fixed vs. Variable Costs

### Fixed Costs

**Definition:**
```
Costs that don't vary with output
Incurred regardless of activity
```

**Examples:**
- Rent
- Salaries (fixed portion)
- Insurance
- Depreciation

**Mathematical:**
```
Fixed_cost = Constant
```

### Variable Costs

**Definition:**
```
Costs that vary with output
Proportional to activity
```

**Examples:**
- Food cost
- Cleaning supplies
- Utilities (variable portion)
- Commissions

**Mathematical:**
```
Variable_cost = Variable_rate × Output
```

### Total Cost

**Function:**
```
Total_cost = Fixed_cost + Variable_cost
Total_cost = FC + VC × Q
where Q = output
```

**Average cost:**
```
Average_cost = Total_cost / Q = FC/Q + VC
```

## Contribution Margins

### Contribution Margin

**Definition:**
```
Revenue - Variable_cost
Contribution to fixed costs and profit
```

**Per unit:**
```
CM_per_unit = Price - Variable_cost_per_unit
```

**Total:**
```
Total_CM = CM_per_unit × Quantity
```

**Percentage:**
```
CM% = CM / Revenue
```

### Break-Even Analysis

**Break-even quantity:**
```
BEQ = Fixed_cost / CM_per_unit
```

**Break-even revenue:**
```
BER = Fixed_cost / CM%
```

**At break-even:**
```
Revenue = Total_cost
Profit = 0
```

## Break-Even Analysis

### Break-Even Point

**Mathematical:**
```
Revenue = Total_cost
P × Q = FC + VC × Q
Q × (P - VC) = FC
Q = FC / (P - VC)
```

**Graphical:**
```
Intersection of Revenue and Total_cost lines
```

### Margin of Safety

**Definition:**
```
Actual_sales - Break_even_sales
```

**Percentage:**
```
MOS% = (Actual - BE) / Actual × 100
```

**Interpretation:**
```
Higher MOS = More safety
Lower MOS = More risk
```

## Operating Leverage

### Definition

**Operating leverage:**
```
Degree to which fixed costs are used
High fixed costs = High operating leverage
```

**Measure:**
```
OL = Contribution_margin / Operating_income
```

**Interpretation:**
- High OL: Small sales change → Large profit change
- Low OL: Small sales change → Small profit change

### Leverage Effect

**Sales increase:**
```
ΔSales → ΔProfit
ΔProfit = ΔSales × CM% (if fixed costs constant)
```

**High leverage:**
```
Large profit swings
Higher risk
Higher potential return
```

## Core Mathematics

### Linear Cost Models

**Total cost:**
```
TC = FC + VC × Q
```

**Average cost:**
```
AC = FC/Q + VC
```

**Marginal cost:**
```
MC = dTC/dQ = VC
```

### Break-Even Equations

**Quantity:**
```
BEQ = FC / (P - VC)
```

**Revenue:**
```
BER = FC / CM%
```

**Price:**
```
BEP = VC + FC/Q
```

**Time:**
```
BET = FC / (CM_per_unit × Units_per_period)
```

### Profit Functions

**Profit:**
```
Profit = Revenue - Total_cost
Profit = P × Q - (FC + VC × Q)
Profit = (P - VC) × Q - FC
Profit = CM_per_unit × Q - FC
```

**Maximization:**
```
dProfit/dQ = CM_per_unit = 0
At optimum: P = VC (not realistic)
```

## Industry Applications

### Menu Engineering

**Profitability matrix:**
```
High_profit, High_popularity: Stars
High_profit, Low_popularity: Plow_horses
Low_profit, High_popularity: Puzzles
Low_profit, Low_popularity: Dogs
```

**Contribution margin:**
```
CM = Price - Food_cost - Variable_labor
```

**Optimization:**
```
Promote high_CM items
Improve or remove low_CM items
```

### Department-Level Profitability

**Department analysis:**
```
Revenue_department
Cost_department
Profit_department
```

**Contribution:**
```
Contribution = Revenue - Variable_cost
```

**Allocation:**
```
Allocate fixed_costs
Calculate department_profit
```

### Pricing Under High Fixed Costs

**High fixed costs:**
```
Need high volume or high price
Or both
```

**Pricing strategy:**
```
Cover variable_cost
Contribute to fixed_cost
Target profit
```

**Mathematical:**
```
Price = VC + (FC + Target_profit) / Expected_quantity
```
