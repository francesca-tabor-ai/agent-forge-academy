- Peer learning and champions
- Continuous improvement

- Risk management

- Performance management
- Resource allocation
- Change management

**Category 3: Individual Contributors**

- Practical workflows
- Problem-solving
- Quality improvement
- Efficiency gains

**Category 4: Technical Teams**
- System integration

- Troubleshooting

**Category 5: Support Functions**

- User assistance
- Feedback collection

### Training Design Principles

- Immediate applicability

- Start with basics

- Enable self-paced learning

**Principle 3: Hands-On Learning**

- Immediate feedback

**Principle 4: Just-in-Time**

## Lesson 6.2: Just-in-Time Enablement

### The Just-in-Time Concept

**Traditional Training:**
- Scheduled sessions
- All content upfront
- Information overload
- Low retention
- Delayed application

**Just-in-Time Enablement:**
- Available when needed
- Contextual and relevant
- Focused and actionable
- High retention
- Immediate application

### Just-in-Time Methods

**Method 1: Contextual Help**

- Tooltips and hints
- Step-by-step wizards
- Interactive tutorials
- Context-aware suggestions

**Method 2: Quick Reference Guides**
- Cheat sheets
- One-page guides
- Video tutorials
- FAQ databases
- Searchable knowledge base

**Method 3: On-Demand Training**
- Self-service modules
- Video libraries
- Interactive courses
- Practice environments
- Assessment tools

**Method 4: Peer Support**
- Internal forums
- Slack channels
- Office hours
- Peer mentoring
- Community of practice

### Implementation Strategy

**Phase 1: Foundation**
- Create knowledge base
- Develop quick guides
- Build video library
- Set up support channels

**Phase 2: Integration**
- Embed in tools
- Add contextual help
- Create searchable resources
- Enable self-service

**Phase 3: Community**
- Build peer network
- Create champions program
- Facilitate sharing
- Encourage collaboration

## Lesson 6.4: Avoiding "AI Theatre"

### What is AI Theatre?

**Definition:**
AI Theatre refers to the performance of using AI tools without actually deriving value, often driven by pressure to appear innovative or modern.

**Symptoms:**
- Tools deployed but not used
- Training completed but not applied
- Metrics tracked but not acted upon
- Adoption reported but not realized
- Value claimed but not demonstrated

### Causes of AI Theatre

**Cause 1: Mandatory Adoption**
- Forced tool usage
- No real need
- Resistance and workarounds
- Surface-level compliance
- No genuine engagement

**Cause 2: Misaligned Incentives**
- Adoption metrics over value
- Activity over outcomes
- Quantity over quality
- Compliance over impact

**Cause 3: Poor Training**
- Theoretical, not practical
- One-size-fits-all
- No follow-up support
- Low relevance
- High complexity

**Cause 4: Tool Mismatch**
- Wrong tools for the job
- Over-engineered solutions
- Under-powered capabilities
- Poor user experience
- Integration issues

### Preventing AI Theatre

**Prevention 1: Value-First Approach**
- Start with real problems
- Demonstrate clear value
- Measure actual impact
- Focus on outcomes
- Celebrate real wins

**Prevention 2: Voluntary Adoption**
- Make tools helpful, not mandatory
- Enable, don't force
- Support, don't pressure
- Reward, don't punish
- Build desire, not compliance

**Prevention 3: Practical Training**
- Role-specific content
- Hands-on learning
- Real-world scenarios
- Immediate applicability
- Continuous support

**Prevention 4: Right Tools**
- Match tools to needs
- Simple and intuitive
- Well-integrated
- Reliable and fast
- Continuously improved

**Prevention 5: Honest Metrics**
- Measure real usage
- Track actual value
- Report honestly
- Address issues
- Improve continuously

## Practical Exercise 1: AI Enablement Plan by Function

### Objective
Create a comprehensive, function-specific AI enablement plan that drives adoption and value.

### Steps

#### Step 1: Map Functions and Roles (30 minutes)

1. **Identify All Functions:**
   - Marketing
   - Sales
   - Product
   - Engineering
   - Customer Success
   - Operations
   - Support functions

2. **Define Roles Within Functions:**
   - Executives
   - Managers
   - Individual contributors
   - Specialists
   - Support staff

3. **Assess Current State:**
   - AI tool usage
   - Skill levels
   - Adoption rates
   - Pain points
   - Opportunities

#### Step 2: Design Function-Specific Training (60 minutes)

1. **For Each Function:**
   - Define learning objectives
   - Identify key use cases
   - Design training content
   - Create hands-on exercises
   - Develop assessment criteria

2. **Create Training Tracks:**
   - Beginner track
   - Intermediate track
   - Advanced track
   - Specialist tracks
   - Leadership track

3. **Design Delivery Methods:**
   - In-person workshops
   - Online courses
   - Just-in-time resources
   - Peer learning
   - Hands-on practice

#### Step 3: Build Enablement Resources (45 minutes)

1. **Create Knowledge Base:**
   - Function-specific guides
   - Use case examples
   - Best practices
   - Troubleshooting
   - FAQs

2. **Develop Quick References:**
   - Cheat sheets
   - One-page guides
   - Video tutorials
   - Interactive demos
   - Practice environments

3. **Build Support Systems:**
   - Help channels
   - Peer networks
   - Champion programs
   - Office hours
   - Feedback mechanisms

#### Step 4: Design Adoption Strategy (30 minutes)

1. **Create Rollout Plan:**
   - Pilot groups

   - Success criteria

2. **Define Success Metrics:**
   - Adoption rates
   - Usage frequency

   - Training objectives
