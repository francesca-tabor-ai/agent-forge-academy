##  Technology Reference

### SDDD Framework Components
- **Specifications** - High-level markdown files (Module 2)
- **Clarification Loops** - AI-driven gap analysis (Module 2)
- **Governing Principles** - Non-negotiable standards (Module 2)
- **Technical Plans** - Architecture and data models (Module 3)
- **Task Breakdown** - Actionable, testable tasks (Module 3)
- **Context Engineering** - Paper trail management (Module 3)

### Quality Assurance Tools
- **TDD Frameworks** - Jest, Mocha, etc. (Module 4)
- **Playwright** - Browser automation (Module 4)
- **Unit Testing** - Test coverage requirements (Module 4)
- **Automated Validation** - CI/CD integration (Module 4)

### SDDD Tooling
- **AWS Kiro** - Three-phase workflow IDE (Module 5)
- **GitHub Spec Kit** - Greenfield project tool (Module 5)
- **OpenSpec** - Brownfield maintenance tool (Module 5)
- **BMAD Method** - Enterprise orchestration (Module 5)

### Enterprise Tools
- **Audit Trail Systems** - Compliance automation (Module 6)
- **Governance Frameworks** - Regulatory compliance (Module 6)
- **Metrics & Analytics** - ROI measurement (Module 6)
