# How to Add a Strong AI Project (2–5 minutes)

Fill in the basics first, then add the AI details if relevant.

## Title (required)

* Use a clear, specific name.
* Format: **What it is + who it's for + key tech**
  Example: *"RAG Support Bot for E-commerce (FastAPI + Pinecone)"*

## Description

Include these 5 bullets (copy/paste and replace):

* **Problem:** What did you build and why?
* **Users:** Who is it for?
* **Approach:** How does it work (high level)?
* **AI/ML:** What models or techniques did you use (RAG, fine-tuning, agents, CV, etc.)?
* **Results:** Metrics, learnings, or impact (latency, cost, accuracy, qualitative feedback).

## GitHub URL

* Link to the repo.
* Make sure your README includes: setup steps, screenshots, and a short architecture note.

## Demo URL

* Link to a live demo or video (Loom/YouTube is fine).
* If it's not public, mention access instructions in the Description.

## Visibility

* **Private:** only you
* **Recruiters Only:** recommended when applying
* **Public:** shareable link on your profile

✅ Tip: If you're unsure, submit now and improve later — you can edit this project anytime.
