# Landing Pages Documentation

This document lists all available landing pages organized by type (tracks, industries, and roles). Each landing page provides a curated view of courses filtered by a specific track, industry, or role, along with subscription options.

## URL Structure

Landing pages follow the pattern:
- **Tracks**: `/landing/track/[slug]`
- **Industries**: `/landing/industry/[slug]`
- **Roles**: `/landing/role/[slug]`

Where `slug` is a URL-friendly version of the display name (lowercase, hyphens instead of spaces and special characters).

## Main Landing Page

The main landing page at `/landing` provides an overview of all tracks, industries, and roles with links to individual landing pages.

## Implementation Details

### Route Files

- **Main landing page**: `app/landing/page.tsx`
- **Track landing pages**: `app/landing/track/[slug]/page.tsx`
- **Industry landing pages**: `app/landing/industry/[slug]/page.tsx`
- **Role landing pages**: `app/landing/role/[slug]/page.tsx`

### Data Sources

- **Tracks**: Dynamically generated from course metadata categories (`lib/course-metadata.ts`)
- **Industries**: Defined in `lib/utils/industries.ts`
- **Roles**: Dynamically extracted from course `bestFor` fields in course metadata (`lib/course-metadata.ts`)
- **Segment utilities**: `lib/utils/segments.ts` provides functions to get segments and their included courses
- **Hero images**: Loaded from `documentation/images/COURSE_IMAGE_URLS.md` for tracks and industries, and from `content/landing/role-images.md` for roles

### Key Functions

- `getSegmentsByType(type)`: Returns all segments of a specific type (track, industry, or role)
- `getSegment(type, key)`: Returns a specific segment by type and key
- `getSegmentKey(type, name)`: Converts a display name to a URL-friendly slug

### Static Generation

All landing pages are statically generated at build time using `generateStaticParams()` to ensure optimal performance and SEO.

## Notes

- Landing pages are only generated for segments that have at least one live course
- Course counts shown on landing pages reflect only live courses
- Each landing page includes subscription options specific to that segment
- Hero images are resolved using the hero image resolver utility (`lib/utils/hero-image-resolver.ts`)
- Role images are sourced from `documentation/images/COURSE_IMAGE_URLS.md` (ROLES section)
- All role landing pages use the same component structure as track and industry pages (`PublicSegmentLandingPage`)
